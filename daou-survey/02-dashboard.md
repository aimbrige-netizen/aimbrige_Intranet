# 다우오피스 채집 — 홈 대시보드

## 레이아웃: 3열 매스너리 (균등 그리드 아님)

```
x=84    폭 298px  (좁은 열)
x=406   폭 693px  (넓은 열)   ← gap 24px
x=1123  폭 693px  (넓은 열)   ← gap 24px
```

- 콘텐츠 시작 x=84 (레일 64 + 여백 20)
- 카드마다 **높이가 다르다**(256~637px). 균등 그리드가 아니라 열 단위로 쌓는 매스너리.
- 우리: 3열 균등 그리드, 카드 6장. 저쪽: **위젯 28장**.

## 카드 스타일
| | 다우오피스 | 우리 |
|---|---|---|
| radius | **12px** | 8px(card) |
| 그림자 | **none** | none (같음) |
| 테두리 | `1px solid rgb(234,236,239)` | `1px solid line` |
| 바깥 padding | 0 (내부 요소가 가짐) | 카드가 가짐 |
| 최소 높이 | 256px 로 정렬된 카드 다수 | 없음 |

## 우리와의 결정적 차이
1. **정보 밀도.** 첫 화면에 28장. 우리는 6장. 스크롤 길이가 아니라 *한 화면에 담긴 판단거리*가 다르다.
2. **열 폭이 비대칭.** 좁은 열(298)에 개인 요약, 넓은 열(693)에 업무. 우리는 3열 균등이라 모든 카드가 같은 폭.
3. **Quick Menu**가 최상단 넓은 열. 우리에겐 없는 개념 — 자주 쓰는 5개 동작을 아이콘 버튼으로.
4. 카드가 **최소 256px**로 정렬돼 리듬이 생긴다. 우리는 내용 길이에 따라 제각각.
