# 다우오피스 채집 — 디자인 토큰 (실측 빈도)

## 타이포
- 폰트: **PretendardVariable** — 우리도 `pretendard` 이미 설치돼 있음
- 크기 빈도: **14px ×1790** / 12px ×25 / 13px ×24 / 18 / 20 / 16 / 10
  → 기본이 **14px**. 우리는 15px(body).
- 굵기 빈도: **400 ×1824 / 500 ×37 / 600 ×5**
  → **700(bold)이 아예 없다.** 강조는 500, 아주 드물게 600.
  → 우리는 `font-bold`(700)를 카드 제목·수치·섹션마다 쓴다. 이게 화면이 시끄러운 큰 원인.

### 가장 큰 시각 차이
**페이지 배경이 회청(237,240,243)이고 카드가 흰색.**
우리는 흰 바탕에 흰 카드 + 테두리라서 카드가 "떠 보이지" 않는다.
저쪽은 배경색 하나로 영역이 갈려서 구조가 즉시 읽힌다. 그림자는 양쪽 다 안 쓴다.

## 지표(대시보드 숫자) 스타일
- 큰 숫자: **28px / 500**
- 활성·잔여 값은 민트 `rgb(68,209,165)`, 총계는 먹색 `rgb(28,28,28)`
- 라벨: 14px / 400 / `rgb(155,156,158)`
- 우리: 값 24~28px/700 + 라벨 11px. → **라벨이 너무 작고 값이 너무 굵다.**
