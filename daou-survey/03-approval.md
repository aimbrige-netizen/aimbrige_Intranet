# 다우오피스 채집 — 전자결재

## 2뎁스 패널 (우리 ModulePanel에 해당)

| | 다우오피스 | 우리 |
|---|---|---|
| 폭 | **260px** | 224px |
| 배경 | 투명(본문과 같은 흰색) | `bg-surface` |
| 우측 경계 | **없음** | `border-r border-line` |
| 모듈 제목 | 20px / 500 | 15px / bold |
| 주요 액션 | `새 결재 진행` 16px/600, **높이 40**, 전체폭, 아웃라인 버튼 | small, primary-low |
| 섹션 제목 | **14px / 600** | 11px(nano) / bold |
| 항목 | **14px / 400, 높이 32px** | 13px, ~30px |

### 핵심 차이
섹션 제목과 항목이 **같은 14px**이고 굵기(600 vs 400)로만 구분한다.
우리는 섹션 제목을 11px로 줄여놔서 위계가 아니라 그냥 작아 보인다.

## 패널 내용 (실제 순서)

```
결재                                    ⋮
[ 새 결재 진행 ]                         ← 전체폭 버튼

결재하기                                 (섹션)
  결재 대기 문서
  결재 수신 문서
  참조/열람 대기 문서
  결재 예정 문서

개인 결재함                           ⚙   ← 섹션에도 설정 아이콘
  <기본 문서함>
  기안 문서함
  임시 저장함
  결재 문서함
  참조/열람 문서함
  수신 문서함
  발송 문서함
  공문 문서함

부서 결재함                              (섹션, 하위 동적)

  ⚙ 결재 환경설정                        ← 하단 고정

결재 문서관리                            (섹션)
  양식별 문서 조회
  전사 공문 발송함
  운영자 작업기록
```

**우리 결재 패널은 항목이 4~5개.** 저쪽은 **18개** + 섹션 4개.
"문서함"을 용도별로 쪼갠 게 핵심 — 기안/임시/결재/참조/수신/발송/공문.

## 본문 (결재 홈)

- 제목 `결재 홈` (x=300, 즉 레일64 + 패널260 뒤)
- 섹션 3개를 세로로: (무제 상단 대기영역) → `기안 진행 문서` ⓘ → `완료 문서` ⓘ
- 섹션 제목 옆에 **ⓘ 도움말 아이콘**
- 각 섹션이 독립 표

### 표 스타일 — 우리와 정반대
| | 다우오피스 | 우리 |
|---|---|---|
| th | 14px / **400**(굵지 않음) | 12px / bold, `bg-subtle` |
| th 배경 | **투명** | 회색 |
| th 밑줄 | **`1px solid rgb(51,51,51)`** 거의 검정 | 연한 회색 |
| td | 14px, padding `8px 0 8px 16px` | 13px |
| 행 구분선 | **없음** | 매 행 연한 선 |

→ 저쪽은 "헤더 아래 굵은 선 하나 + 행 구분선 없음". 우리는 "회색 헤더 + 모든 행에 선".
   저쪽이 훨씬 가볍고 표가 길어져도 시끄럽지 않다.

### 표 컬럼
`기안일 | 결재양식 | 긴급 | 제목 | (여백) | 첨부 | 결재상태`
완료 문서는 `... | 첨부 | 문서번호 | 결재상태`

- 제목이 **flex-grow**로 남는 폭을 다 먹고, 우측 메타(첨부·상태)는 고정폭 우측 정렬
- 빈 상태: 일러스트 + "문서가 없습니다."

## 상단바 연동
검색창 좌측 스코프가 `전체 앱 ▾` → **`결재 ▾`**로 바뀐다. 모듈 진입 시 검색 범위가 따라감.
