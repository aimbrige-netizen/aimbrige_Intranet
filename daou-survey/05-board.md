# 다우오피스 채집 — 게시판

## 패널
```
게시판                          ⋮
[ 글쓰기 ]                       ← 전체폭 버튼 (결재의 '새 결재 진행'과 같은 자리)

전사게시판                       (섹션)
  전사 공지
  전사 알림

부서게시판                       (섹션)
  소속된 부서가 없습니다.
  운영자에게 문의하세요.          ← 빈 상태를 패널 안에서 설명

  + 게시판 추가                   ← 하단, 아이콘+텍스트
```

## 본문
- 제목 `게시판 홈`
- **필터 칩 줄**: `즐겨찾기` / `전체 게시판`
  - 활성 칩 = **검정 알약**(bg 검정, 흰 글자)
  - 비활성 = 흰 배경 + 연한 테두리
  - 우리는 활성 칩이 primary-light(연한 오렌지). 저쪽은 검정이라 훨씬 또렷하다.
- 빈 상태: 일러스트 + 안내문 + **시안 CTA 버튼**(`새 글 작성하기`)
  - 우리 EmptyState는 secondary 버튼. 저쪽은 브랜드색 채운 버튼.

## 미채집
`인사(/ess/app/#hr)`는 **간편 비밀번호 4자리 등록**을 요구해서 들어가지 않았다.
계정에 인증수단을 새로 만드는 동작이라 대신 수행하지 않음.
급여·계약·교육·경비·차량일지도 같은 ESS 앱이라 같은 관문일 가능성이 높다.
